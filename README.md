# TCFD-AI：氣候變遷與天然氣使用量分析系統

以歷史氣象資料、天然氣使用量及未來氣候情境，分析氣候條件與民生天然氣需求之間的關聯。

## 專案簡介

本專案以大台北區瓦斯股份有限公司為研究對象，探討氣候因素與民生天然氣使用量之間的關聯，並結合未來氣候變遷情境，推估不同氣候條件下天然氣使用量的可能變化。

專案整合歷史氣象資料、天然氣使用量、用戶數及公開財務資訊，使用 Python 進行資料處理、統計分析與機器學習建模，並以 Streamlit 建立互動式資料分析系統。

本作品參與 AI 資料創新應用競賽。原始 Repository README 記載競賽成果為「TCFD 實務組冠軍」；此處沿用原始專案紀錄。

## 研究目標

1. 分析歷史氣象條件與民生天然氣使用量之間的關聯。
2. 探討氣溫及體感溫度對天然氣總使用量與每戶平均使用量的影響。
3. 建立氣象變數與天然氣使用量之間的線性迴歸模型。
4. 結合未來氣候變遷情境，推估不同情境下天然氣使用量的可能變化。
5. 透過互動式視覺化介面呈現資料分析及情境推估結果。

## 系統功能

系統主要分為四個功能區：

### 1. 大台北瓦斯公司簡介
介紹研究對象及相關背景資訊。

### 2. 資料集與視覺化分析
整合歷史氣象、天然氣使用量及相關營運資料，透過圖表呈現氣象條件與天然氣使用量的變化關係。

### 3. 機器學習分析
使用 Scikit-learn 建立線性迴歸模型，分析氣象變數與天然氣使用量之間的關係，並呈現模型評估結果。

### 4. 未來氣候情境推估
結合 RCP2.6、RCP4.5、RCP6.0、RCP8.5 四種氣候情境，呈現未來氣溫變化與天然氣使用量的推估結果。

## 資料處理與分析方法

### 歷史氣象資料

- 歷史資料期間：2013 年 2 月至 2020 年。
- 使用臺北、天母、士林、信義、松山、平等及社子等七個平地測站。
- 整合氣溫、相對濕度、風速及體感溫度等氣象指標。
- 測站選擇以研究區域的平地環境為考量，降低山區氣候差異對代表性的影響。

### 天然氣使用量資料

整合歷史天然氣使用量及年度用戶數，建立總用氣量與每戶平均用氣量等分析指標。

每戶平均用氣量的計算方式為：

`每月總用氣量 ÷ 該年度用戶數`

計算時以年度用戶數作為該年度各月份的分母，並非逐月變動的用戶數。

### 未來氣候情境

研究使用 TCCIP（臺灣氣候變遷推估資訊與調適知識平台）相關氣候推估資料，涵蓋以下四種 RCP 情境：

- RCP2.6
- RCP4.5
- RCP6.0
- RCP8.5

依專案企劃資料紀錄，未來氣候推估採用 IPSL_CM5A_LR 氣候模式，並選取研究區域內的七個網格點進行資料整合。

## 機器學習方法

本專案使用 Scikit-learn 的 `LinearRegression` 建立線性迴歸模型，分析氣象變數與天然氣使用量之間的關係。

建立四組分析模型：

| 輸入變數 | 預測目標 |
|---|---|
| 氣溫 | 天然氣總使用量 |
| 體感溫度 | 天然氣總使用量 |
| 氣溫 | 每戶平均天然氣使用量 |
| 體感溫度 | 每戶平均天然氣使用量 |

模型訓練與評估設定：

- 訓練集／測試集比例：70%／30%
- `random_state=22`
- 評估指標：RMSE、R²
- 使用 Seaborn 呈現迴歸分析結果。

未來情境推估以氣溫作為主要輸入變數，原因是研究採用的未來氣候資料未提供相應的未來體感溫度資料。

## 專案成果與技術反思

本專案完成從多來源資料整合、統計分析、機器學習建模到互動式網頁應用的實作流程。

回顧當時的技術設計，仍有值得進一步改善的地方：

1. **模型驗證方式：** 當時採用隨機方式切分訓練集與測試集。若重新開發，可進一步評估依時間順序切分資料，以更符合時間序列資料的特性。
2. **模型與推估流程整合：** 可將模型訓練結果與未來情境推估流程整合，避免模型係數分別維護。
3. **資料來源與可重現性：** 可補充資料版本、下載日期、授權資訊及資料處理流程，提升研究的可追溯性。
4. **模型解釋與預測限制：** 線性迴歸呈現的是資料中的統計關聯，不代表氣溫是影響天然氣使用量的唯一因素，也不代表模型能完整預測企業未來獲利。
